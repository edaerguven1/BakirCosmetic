# Bakır Cosmetic 💄✨

Bakır Cosmetic, kozmetik ve güzellik ürünlerinin tanıtıldığı, modern ve estetik bir web platformudur. Bu proje, kullanıcı dostu arayüzü ve dinamik 3D görsel efektleriyle öne çıkmaktadır.

## 🌟 Özellikler
- **Modern Tasarım:** Şık ve premium hissettiren kullanıcı arayüzü (HTML5 & CSS3).
- **Dinamik 3D Efektler:** Etkileyici ürün sunumları için 3D Hero ve Carousel animasyonları.
- **Katalog ve Ürün Yönetimi:** Çeşitli marka ve ürünlerin listelendiği, detaylı ürün sayfaları.
- **Responsive (Duyarlı) Tasarım:** Tüm cihazlarda (mobil, tablet, masaüstü) kusursuz görünüm.
- **Admin & Stüdyo Sayfaları:** Ürün yönetimi ve özel içerikler için ayrılmış detay sayfaları.

## 📂 Proje Yapısı
- `index.html`: Ana sayfa
- `products.html` & `product-detail.html`: Ürün listeleme ve detay sayfaları
- `catalogs.html`: Kozmetik kataloglarının bulunduğu sayfa
- `studio.html`: Özel stüdyo ve görsel sunum sayfası
- `about.html`: Hakkımızda
- `contact.html`: İletişim formu
- `admin.html`: Yönetim paneli arayüzü
- `style.css`: Tüm sitenin stil tanımlamaları
- `main.js`, `hero-3d.js`, `carousel-3d.js`: Etkileşim ve animasyon komut dosyaları
- `data/`: Ürün veritabanı dosyaları (JSON / JS)
- `assets/`: Resim, video ve PDF gibi görsel ve belgeler

## 🚀 Kurulum ve Çalıştırma
Projeyi yerel bilgisayarınızda çalıştırmak için:

1. Depoyu bilgisayarınıza klonlayın:
   ```bash
   git clone https://github.com/edaerguven1/BakirCosmetic.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd BakirCosmetic
   ```
3. Herhangi bir yerel HTTP sunucusu kullanarak projeyi çalıştırın. *(Örn: VS Code Live Server eklentisi veya Node.js ile `npx http-server` komutu kullanılabilir.)*
